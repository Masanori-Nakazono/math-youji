# かずのぼうけん

小学校入学までの半年で、年長児が身につけておきたい算数の土台を、
iPad をタップしながら遊んで獲得するためのアプリ。

- 全 15 の遊び × 各 3 レベル（計 45 レベル / 360 問相当）
- 4 つの世界に整理：かずの しま／くらべる うみ／けいさんの やま／かたちの もり
- 1 レベル 8 問・1 日 10 分。時間制限も減点もなく、2 回間違えると自動でヒントが出る
- 星・シールブック・「きょうの れんしゅう」（全体から 10 問）で毎日続く設計
- 保護者向けページ：世界別の到達度・初回正答率、半年のロードマップ、家庭での声かけ例
- 記録は端末の localStorage のみ。通信も送信も一切なし。単一 HTML ファイルで動作

## iPad に入れる

**方法 A：ホーム画面に追加（おすすめ）**
1. `dist/kazu-no-bouken.html` を iCloud Drive などに置くか、任意の場所に公開する
2. Safari で開く → 共有ボタン → 「ホーム画面に追加」
3. アイコンから起動するとブラウザの UI が消え、アプリのように全画面で動く

**方法 B：ファイルをそのまま開く**
`dist/kazu-no-bouken.html` を AirDrop などで iPad に送り、ファイルアプリから Safari で開く。
ただし `file://` で開くと iPadOS 側がデータ保存を許可しないことがあり、**その場合は
学習の記録が毎回消えます**（保護者ページに警告が出ます）。半年続けるなら方法 A を
使ってください。ホーム画面に追加していない Safari のタブも、7 日間使わないと
iPadOS が保存データを破棄します。

いずれも初回だけネットワークがあると Google Fonts が読まれます。オフラインでも
iPad 内蔵のヒラギノ丸ゴにフォールバックするので、見た目が少し変わるだけで全機能が動きます。

**動作要件**：iPadOS 16.2 以降（`color-mix()` と `:focus-visible` を使っています）。
それ以前の iPad では図形の輪郭など一部の色が出ません。

**音声について**：問題文は日本語で読み上げられます。声が出ない場合は
iPad の 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 で
Kyoko などを追加してください。文字だけでも遊べます。

## ソースと再ビルド

```
src/
  head.html      <title> と Google Fonts の読み込み
  body.html      #stage と #fx だけの器
  styles.css     デザイントークン（画用紙とクレヨン）と全画面分のスタイル
  js/
    00-util.js       DOM ビルダー、乱数、日本語の数の読み
    01-audio.js      WebAudio による効果音の合成 と 音声読み上げ
    02-store.js      進捗の保存（localStorage）
    03-art.js        マスコット・星・図形・時計・数字の筆順データ
    04-ui.js         画面遷移、紙吹雪、ドラッグ＆ドロップ
    05-engine.js     ゲーム登録と出題セッションの進行
    10-g-number.js   かずの しま の4遊び
    11-g-compare.js  くらべる うみ の3遊び
    12-g-calc.js     けいさんの やま の4遊び
    13-g-shape.js    かたちの もり の4遊び
    90-screens.js    タイトル・ホーム・レベル選択・結果・シールブック
    91-parent.js     保護者ページ
    99-main.js       起動、スケール調整、iOS のズーム抑止
```

```bash
./build.sh
```

ビルドは `src/js/*.js` を名前順に連結します。数字プレフィックスが読み込み順です。
新しいファイルを置けば自動で入るので、リストを更新し忘れる事故は起きません。

生成物：
- `dist/kazu-no-bouken.html` — 単独で開ける完全な HTML（iPad 用はこちら）
- `dist/artifact.html` — Artifact として公開する用（doctype/head/body は外側が用意する）

ビルドは `node --check` で構文検査をしてから出力します。

## テスト

```bash
python3 -m http.server 8731     # プロジェクト直下で
```
ブラウザで `http://127.0.0.1:8731/test/index.html` を開くと回帰テストが走ります。
アプリを iframe に読み込み、実際に答えをタップして「そのあと何が起きたか」を検証します。

問題を **作れる** ことだけを確認しても、対話のバグは1つも見つかりません。
実際に初版では、正解を押した後の挙動を誰も検証していなかったために、
「穴が2つある問題が1つ目で終わってしまう」「前の問題のタイマーが次の問題を
勝手に正解にする」といったバグが素通りしていました。テストはそこを狙って書いてあります。

| 検証 | 何を守っているか |
|---|---|
| no question completes while blanks remain | 複数回答の問題が途中で終わらない |
| one answer never advances more than one question | 1回の正解で1問だけ進む |
| every level is playable through to the result screen | 全45レベルが最後まで遊べる |
| leaving a question cannot advance the next level | 中断しても前の問題のタイマーが残らない |
| a story animation cannot write into the next question | アニメ中に抜けても次の画面を壊さない |
| leaves no handlers behind | 共有ノードにリスナが溜まらない |
| a hint is never stacked up | ヒントが重複しない |
| two wrong answers always change something on screen | 読み上げオフでも必ず画面が反応する |
| tracing counts misses | なぞり書きが常に★3にならない（保護者ページの数字が嘘にならない） |
| clock hours read よじ / しちじ / くじ | 時計の読みが「よんじ」にならない |
| no role=button without keyboard support | 見た目がボタンなら必ずキーボードでも押せる |
| answer sets have no duplicate labels | 選択肢が破綻しない |
| every sticker slot has its own emoji | シールが重複しない |

## 遊びを増やす

`src/js/1x-g-*.js` に `Games.add({...})` を足すだけで、ホーム画面・レベル選択・
「きょうの れんしゅう」・保護者ページのすべてに自動で載ります。

```js
Games.add({
  id: 'myGame', name: 'あたらしい あそび', ico: '🎲',
  world: 'shima',                 // shima | umi | yama | mori
  color: 'var(--c-blue)',
  aim: '保護者ページに出る「この遊びで つく ちから」',
  levels: [
    { t: 'レベル名', d: 'ひとこと説明', n: 8, make(api){
        api.setPrompt('といかけ', '読み上げる文');
        api.field.append(/* 問題の見た目 */);
        api.buildChoices([1,2,3], 2);   // 正解は 2
        api.onHint(() => { /* 2回間違えたときに呼ばれる */ });
      } }
  ]
});
```

`api.correct()` を呼べば正解、`api.wrong(el)` で不正解。自作の操作で解かせる遊びは
この 2 つを自分で呼べば、進行・星・シールはエンジン側が面倒を見ます。

**遅延処理は必ず `api.later(fn, ms)` を使ってください**（`setTimeout` は使わない）。
問題を離れると自動でキャンセルされるので、アニメーションの途中で「もどる」を
押されても、前の問題が次の問題を書き換えることがありません。

複数の答えを順に聞く問題は `buildChoices` の `onPick` で `false` を返します。
`false` のあいだ問題は開いたままになり、最後の正解でだけ次へ進みます。

```js
api.buildChoices(values, answer, {
  onPick(){ /* 1つ埋める */ return more ? false : true; }
});
```

KazuApp.Session.startLevel(KazuApp.Games.byId.bond, 2);  // 特定レベルへ直行
