# 子供一人専用のポケモンシール素材

312種類（1周目156種類・2周目156種類）のイラストは [PokéAPI/sprites](https://github.com/PokeAPI/sprites) の
`sprites/pokemon/other/official-artwork/{id}.png` から取得しました。
背景の透明を保ち、最大256×256のWebPに変換しています。
カタカナ名、伝説・幻の分類は [PokéAPIのCSVデータ](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)
に基づきます。1周目の素材は2026-10-04および2026-10-05、2周目の156種類は2026-10-15に取得しました。

各画像の出典URLと保存ファイルのSHA-256は `manifest.json` に記録しています。
ポケモンの画像・キャラクターに関する権利は各権利者に帰属します。
この収録は利用者の子供一人専用の用途です。公開・配布用の素材集ではありません。

レア度はこの算数学習アプリ独自の設定で、公式ゲームでの出現率ではありません。

- なかま（1）：前半の通常レベル、日々の練習、短い冒険の参加シール。
- レア（2）：各遊びの最終レベルの進化形、1年生の通常シール。
- スーパーレア（3）：各レベルで全問初回正解した金シール。
- でんせつ（4）：各ワールドの金シールを全部集めて開く宝箱。
- とくべつ（5）：60レベルの通常シールを確定し、全クリア後の冒険で5問中4問以上を
  ヒントなしで初回正解したシール。特別な伝説と幻のポケモン。

1周目は、通常・金・宝箱・特別の131枠と、教科書のレッスン20枠・まとめ5枠を合わせた156枠です。
教科書用の既存キー `r2:0..19` / `r2chapter:0..4` も1周目に含まれます。
`manifest.slots` は既存の156種類の割り当てを保持しています。

2周目は、同じ156枠すべてに1周目とは異なるポケモンを `manifest.roundTwoSlots` で固定しています。
通常140種類・伝説12種類・幻4種類を各周に収録し、各キーのレア度と伝説・幻の分類を維持しています。
312枠で種の重複はありません。2周目のシールには青い「２しゅうめ」のマークが付き、
教科書のまとめシールは金の枠・紫のマークで区別できます。

日付ごとの参加シールは、各周専用の通常ポケモン32種類から固定ハッシュで選びます。
参加シールから伝説・幻は出ません。割り当てはゲームの登録順に依存せず、実行時のランダム抽選も行いません。

通常の `./build.sh` はネット接続を使わず、画像をHTML内のdata URLに埋め込みます。
単体HTMLの保存・オフライン起動でも画像と名前が表示されます。
素材を再取得する場合のみ `python3 tools/fetch-pokemon.py`（Pillowとネット接続が必要）を実行します。

`PokemonStickers.reward(key, round)` と `artwork(key, { round })` は周を明示でき、
省略時は `Store.round()` を参照します。`lap2:` を付けた島用キーは、表示中の周にかかわらず2周目を示します。
`isSecondRound(key, round)` も同じ規則で判定します。
通常のビルドでは、両周の156キーの一致、312種類の一意性、周をまたぐレア度・分類の一致、
各WebPのSHA-256、および参加シールの候補がその周の通常種であることを検証します。
